# TreorAI

An AI-powered guidance counsellor is proposed as a solution for this Human-Computer Interaction group project originally completed for the HCI module at UCD.

## What is this project?
The task was to find an inequality in the world (specified in Sustainable Development Goal 10) and to use HCI principles to research and design a solution to that problem.

We observed the disparity between the proportion of DEIS students (poor socio-economic backgrounds) in schools as compared to in universities. Fee-paying schools tend to have a much higher conversion rate in this area. We deduced that this was due to a lack of university-related information being available to said students.

So, we designed an AI-chatbot that could act as a kind of guidance counsellor, using only official sources and using language suitable for teenage users.
